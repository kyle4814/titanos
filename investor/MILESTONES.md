# TitanOS — Evidence-Gated Milestones

| Stage | Evidence required | Status |
|---|---|---|
| Core engine | reproducible tests + documented limitations | Inspect repository |
| External validation | repeatable real-world experiments | Inspect experiments |
| Commercial validation | paid customer outcome | Not assumed |
| Repeatability | repeated outcomes with measured economics | Not assumed |
| Scale readiness | measured workload, reliability and unit economics | Not assumed |

This table deliberately avoids invented percentages, valuations or forecasts.

## Capital gate

A new spending category should answer:

**What bottleneck does this remove?**

**What measurement will change if it works?**

**What evidence causes us to stop spending?**

If those answers cannot be stated, the spend is not yet evidence-gated.
