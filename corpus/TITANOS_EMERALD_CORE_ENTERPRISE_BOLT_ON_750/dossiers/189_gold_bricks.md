# EMERALD DOSSIER 189 — GOLD_BRICKS

## Doctrine
SEARCH BEFORE BUILD. REUSE BEFORE DUPLICATE. VERIFY BEFORE PROMOTION.

## Contract
The agent must inspect existing repository capability, identify the smallest
high-leverage change, execute within an explicit scope, test behaviour, and
persist a durable receipt.

## Statelessness
Agent context is disposable. Durable knowledge belongs in repository artifacts,
configuration, queues, receipts, checkpoints and outcome ledgers.

## State vocabulary
DECLARED != SCAFFOLD_ONLY != IMPLEMENTED != VERIFIED != REALIZED.

## German engineering
Remove duplication, stale claims, dead configuration, hidden side effects and
ambiguous interfaces. Tests prove behaviour rather than comments.

## Acceptance
Unproven claims remain unresolved. Completion is an evidence-backed state.
