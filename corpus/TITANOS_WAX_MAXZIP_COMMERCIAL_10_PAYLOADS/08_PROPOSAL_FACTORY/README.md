# TITANOS — 08_PROPOSAL_FACTORY

## Mission
Convert qualified opportunities into evidence-backed proposal workpacks.

## Canonical execution
RECON → SEARCH → INVENTORY → VERIFY → SCORE → REUSE → GAP DETECTION → TOOL/API DISCOVERY → IMPLEMENT → TEST → DEMONBLADE → RECEIPT → BRICK → PARETO → NEXT ACTION

## Hard gate
SEARCH BEFORE BUILD.

1. Inspect the existing repository and canonical state.
2. Search for existing capability.
3. Search authoritative/public sources relevant to the task.
4. Reuse before adapting.
5. Search for suitable APIs.
6. Search for suitable free/open tools.
7. Search GitHub for suitable existing implementations.
8. Build only the smallest missing capability.
9. Test and attack the result.
10. Record provenance and a receipt.
11. Promote only verified reusable capability to Gold Brick.
12. Recalculate the Pareto frontier.

## Evidence doctrine
Never fabricate demand, tenders, customers, traction, revenue, investment returns, citations, certifications or search visibility.

Distinguish:
OBSERVED / VERIFIED / INFERRED / MODELLED / REALIZED.

## Safety
Use only lawful, authorised data access. Respect privacy, access controls, terms, robots policies and rate limits. Material financial commitments and legally binding submissions require appropriate human authority and review.
