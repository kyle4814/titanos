# Security Baseline

- Never commit secrets, API keys, private credentials, or raw sensitive personal data.
- External node provisioning requires explicit authorization and budget controls.
- Least privilege applies to workers and integrations.
- High-impact actions require human escalation where policy requires it.
- Receipts must identify what happened without unnecessarily exposing sensitive data.
- Certificates must not claim legal approval merely because an automated check passed.
- Financial participation must not be represented as guaranteed return.
- Public OSINT signals require provenance and appropriate corroboration.
