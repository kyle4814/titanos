# TITANOS — CRAWLER BUDGET
PACKAGE: MAX NUKE 014
DOMAIN: 02_WEB_SEARCH_DISCOVERY
STATUS: DRAFT SENSOR / DISCOVERY ENGINEERING SPEC

PURPOSE
Define a bounded, measurable mechanism for `crawler_budget`.

LOOP
DISCOVER → INGEST → NORMALIZE → VERIFY → INDEX → MEASURE → ATTRIBUTE → MUTATE

RULES
- use authorised, lawful data access
- respect robots, rate limits, terms and privacy requirements
- preserve provenance
- distinguish observation from inference
- distinguish traffic from attention
- distinguish attention from conversion
- distinguish forecast from realized revenue
- never fabricate traction, citations, rankings or customers
- make every consequential automation bounded and auditable

PARETO
Prioritise the smallest verified change with the greatest discovery,
authority, conversion or risk-reduction leverage.

VIRALITY IS AN OUTCOME TO MEASURE, NOT A GUARANTEE.
